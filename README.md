# Kenya AI Compute Infrastructure Platform

This repository contains the Next.js 14 scaffold for the Kenya AI Compute Infrastructure Project. The current state provides the locale-aware routing, public/portal structure, shared layout components, and design-system seed so that content, calculators, and integrations can be implemented next.

## Quick start

```bash
npm install
npm run dev
```

## Project focus

- Locale-aware public site and portal structure.
- Tailwind-based design system seed.
- Future additions: content, calculators, visualizations, and integrations.

## Status

Scaffold is in place. The next step is implementing real page content and interactive components per the technical specification.
