## Известные ограничения среды

- В текущем окружении периодически проявляется ограничение `spawn EPERM` для `next dev`.
- Из-за блокировок файлов на Windows часть логов/кэша может не удаляться при активном процессе Node.
- Для стабильной демонстрации рекомендуется использовать `npm run build && npm run start -- -p 3000`.
