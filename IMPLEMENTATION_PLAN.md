# План реализации платформы Kenya AI Compute

## 1. Архитектурные потоки (как системный архитектор)

### 1.1 Поток A — Основной продукт (Public + Portal)
- **Цель:** быстро поднять информационную часть + базовый портал.
- **Результат:** полный sitemap, навигация, единый дизайн, первичный контент.

### 1.2 Поток B — Интерактивные модули
- **Цель:** ROI/финансовые калькуляторы, pricing калькулятор, DePIN estimator.
- **Результат:** готовые компоненты, mock-данные, визуализации.

### 1.3 Поток C — Инфраструктура и безопасность
- **Цель:** аутентификация, роли, безопасность, i18n, SEO.
- **Результат:** RBAC, next-intl, middleware, базовые метатеги.

### 1.4 Поток D — Контент и локализация
- **Цель:** полноценный контент на EN/RU/ZH.
- **Результат:** тексты, CTA, SEO-метаданные, alt-тексты.

## 2. План реализации (как разработчик)

### Этап 1 — Каркас проекта
- Bootstrap Next.js 14
- Tailwind + базовые компоненты
- Базовые layout + header/footer
- I18n routing + middleware

### Этап 2 — Полная структура страниц
- Генерация всех страниц из ТЗ
- Базовые заголовки/описания
- Навигация и футер

### Этап 3 — Блоки ключевых страниц
- Главная: hero + value props + KPI
- Инвесторы: тезис + финансы
- Compute: overview + DePIN

### Этап 4 — Интерактивные компоненты
- ROI Calculator (mock)
- Pricing Calculator (mock)
- DePIN Estimator (mock)

### Этап 5 — Portal + роли
- Login/Register UI
- Внутренние разделы (investor, partner, customer, admin)

### Этап 6 — SEO и контент
- Метаданные на всех страницах
- Schema markup (шаблон)
- Sitemap/robots

## 3. Параллельные процессы
Чтобы ускорить, можно делать **параллельно**:
- Поток A (структура страниц) + Поток B (калькуляторы)
- Поток C (security/i18n) + Поток D (контент)

Итог: быстрый выход на MVP, потом наполнение контентом и визуализациями.
